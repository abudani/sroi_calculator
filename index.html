☁️ Integración Salesforce ▶

Cada proyecto se guarda con un esquema compatible con Salesforce. Para conectarlo, creá el objeto SROI_Calculation__c con estos campos:

Name · Organization__c · Investment__c · Period_Years__c · SROI_Ratio__c · Stakeholder_Count__c · Outcome_Count__c · JSON_Data__c (Long Text Area)

Luego reemplazá StorageAdapter en el código por llamadas a la API REST de Salesforce. El campo JSON_Data__c almacena el estado completo y los demás campos quedan indexados para reportería.
